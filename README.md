# AI Resume Analyzer

A responsive single-page web application that helps students and job seekers evaluate resumes against job descriptions.

## Features
- ATS compatibility scoring
- Keyword match analysis
- Missing-skills identification
- Improvement recommendations
- Sample resume/job input for quick testing
- Clean, mobile-friendly layout

## Live preview
Open the project in a browser using a local static server.

## Run locally
1. Open a terminal in the project folder.
2. Run:
   ```bash
   python -m http.server 8000
   ```
3. Open http://localhost:8000 in your browser.

## Project structure
- `index.html` — landing page and app layout
- `styles.css` — styling and responsive design
- `script.js` — ATS analysis logic

## Purpose
This project supports better job readiness by helping users identify resume weaknesses, keyword mismatches, and missing skills before applying to roles.
